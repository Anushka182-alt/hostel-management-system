# Hostel Guest Room Reservation System
A desktop-based Hostel Guest Room Reservation System developed using Python and Tkinter.

# Project Overview
This project provides a simple graphical interface for managing hostel guest room reservations. It allows users to enter student and guest details, manage room bookings, and maintain booking records using file handling.

# Features
- Student ID based booking
- Guest registration
- Room number management
- Number of days for stay
- Booking status management
- View booking records
- File-based data storage
- User-friendly Tkinter GUI

# Technologies Used
- Python
- Tkinter
- File Handling
